모바일 원페이지 청첩장 — 사용 방법
================================

1. index.html을 크롬, 사파리 등 브라우저로 열면 바로 볼 수 있습니다.
   인터넷 연결 없이도 웹페이지와 사진이 보입니다.
   단, [구글 지도로 길찾기]는 인터넷이 필요합니다.

2. 폴더 구조
   wedding_invitation_site/
   ├─ index.html          (구조와 표시 문구)
   ├─ style.css           (색상, 글씨 크기, 모바일 레이아웃)
   ├─ script.js           (달력, 사진 확대, 복사 팝업)
   ├─ README.txt          (이 문서)
   └─ assets/
      ├─ map-preview.svg  (장식용 예시 약도, 실제 지도 아님)
      ├─ decor-sprig.svg   (투명 배경 식물 장식)
      └─ images/          (실제 로컬 이미지 파일 10개)

3. 내용을 수정하는 방법
   - 신랑/신부 이름: index.html에서 '김민준', '이서연' 찾기
   - 일시: index.html에서 '2027' 또는 '05월 22일' 찾기.
           달력 날짜도 바꾸려면 script.js의 WEDDING_DATE 수정.
           JS는 1월 = 0, 5월 = 4로 입력합니다.
   - 예식장/주소: index.html의 '그랜드 워커힐 서울'과 주소 수정.
   - 구글 지도: index.html에서 'https://www.google.com/maps/search/'가
     포함된 두 href를 원하는 장소의 구글 지도 URL로 수정.
   - 계좌/은행: index.html의 data-owner, data-bank, data-account와
     카드에 표시된 정보 모두 수정.
   - 색상: style.css 상단 :root 설정 수정.
   - 웨딩 사진: assets/images 파일을 본인의 사진으로 교체.
     파일 이름을 같게 유지하면 HTML을 수정할 필요가 없습니다.

4. 작동 방식
   - 사진을 클릭: 크게 보기 팝업 / 좌우 버튼 및 키보드 좌우 화살표 / ESC 닫기
   - 복사 버튼: 계좌번호 복사 시도 후 결과 팝업 표시
   - 구글 지도 버튼: 새 탭으로 구글 지도 검색 열기
   - 메뉴: 페이지 내 해당 구역으로 스크롤

5. 이미지 출처 및 주의사항
   이 프로젝트의 예시 사진은 사용자가 제공한 시안 이미지에서 사진 영역을
   분리하여 로컬 WebP 파일로 저장한 것입니다. 별도의 외부 사진 URL이
   필요하지 않습니다. 원본이 하나의 시안이므로 개별 사진 해상도에는
   제한이 있고, 실제 공개 사용 전 사진 권리를 확인하고 본인 사진으로
   교체하는 것이 좋습니다.

   이름, 부모님 이름, 일자, 예식장, 계좌번호 등은 모두 예시 정보이며,
   개인 청첩장으로 사용하기 전 반드시 실제 정보로 바꾸세요.
   예시 약도는 실제 도로 위치를 나타내지 않습니다. 길찾기는 구글 지도를 사용하세요.

6. 업로드 방법
   index.html 파일만 업로드하지 말고, CSS/JS/assets 폴더를 통째로
   웹호스팅 또는 GitHub Pages, Netlify 등에 업로드하세요.
   개인정보(특히 계좌번호)를 넣은 사이트를 공개할 때는 공개 범위를 고려하세요.
